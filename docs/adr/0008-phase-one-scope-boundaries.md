# ADR-0008: 一期边界——显式不做清单

状态：accepted（2026-08 敲定）

一期内容：窑炉、Duo、电力节点、材料链，外加一个 2x2 结构用于验证蓝图管线。以下能力被明确排除，是为防止后续开发把"没做"当成"忘了"或随手补出半套：

- **液网**：液体只能以桶灌入机器内罐；冷却/加成角色一期即数据化并可玩（往 Duo 里倒桶水成立），但管道/泵网络随二期开启（复用电网的图染色机制）。
- **GUI**：无任何自定义界面，状态全靠 Jade 悬浮 + 本体视觉。
- **维修**：HP 单向，碎完重建。Mindustry 的修理器（reconstructor，半径场修建筑）与 mender（修单位）属战役/单位期；手持材料维修被否决（非 Mindustry 机制）。
- **ghost 放置预览**：蓝图校验失败只拒绝 + actionbar 提示。
- **吸附缩放构件**（风车式数量→性能）：接口不预留。
- **Flywheel 缺席回退渲染路径**：内嵌依赖无缺席分支。
- **子弹的实体化瞬时家族**：闪电/激光走射线判定零实体（ADR-0006），不为其建实体。
- **传送带**：只作为上述范式的验证用例拷问设计，其自身机制（带内物品=BE 数据已定，见 research 文档 §4.4）另开设计轮。
