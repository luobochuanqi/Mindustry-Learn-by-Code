# ADR-0010: 子弹扫掠碰撞语义——起止并集单查询 + 段-盒进入点命中

状态：accepted（2026-09-01 敲定，#53）

飞行弹每 tick 的实体碰撞判定改为**起止两盒并集**（prev `minmax` current）的**单次查询**，查询结果由"撞方块消失"与"撞怪消失"两分支共用；非撞墙命中的结算点取**路径上最早进入候选箱体的进入点**（段-盒 slab 测试），溅射衰减与破片生成以该点为中心。撞墙命中仍以墙停位置为准。

动机有三：① 原静态盒只查 tick 末位置，高速弹（Scatter 铅弹 1.575 格/tick）可整段跨过 0.5 宽薄怪而不结算（方块不会——`move()` 自带扫掠）；② `impact()` 对同一批实体二次查询，每 tick 成本翻倍；③ 扫掠盒一旦采用，命中点从"tick 末位置"变成歧义——若不定义，溅射/破片在高速弹下偏后最多 1.5 格。

关键语义：

- **撞墙分支共享扫掠列表**：撞墙时路径上被穿过的怪同样结算直击——行为是旧语义的超集（墙停位置本就在并集盒内，无回退），顺带修掉旧怪癖"子弹穿怪后撞墙、只有贴墙怪吃伤害"。move() 被阻挡时实际路径（按轴分解）单调含于并集盒内，并集查询对轴锁路径是保守近似，无漏。
- **进入点 = 命中点**：对每个候选做段-盒测试（候选盒同查询口径 inflate 0.15），取最早 t ∈ [0,1] 者；仅靠 inflate 余量蹭到、未被穿过的候选不提供命中点（此时退回 tick 末位置）。多候选同 tick 重叠时"最早进入者"即真命中者，直击伤害仍按全列表结算（各自独立，ADR-0006/#34 直击+溅射独立语义不变）。
- **撞墙命中点 = 墙停位置**：与旧行为一致。
- 溅射距离口径从"到子弹位置"改为"到命中点"（`distanceToSqr(origin)`），扫掠命中时不再偏置。
- 无碰撞时实际路径为直线段，并集查询与逐候选精判**等价**；有碰撞时接受并集近似——不值得为角落差写第二套判定。

配套客户端语义（同票）：lifetime 打包进同步色顶字节供客户端推导收缩进度（渲染只取 RGB，零新增同步字段）；朝向走原版 yRot/xRot 同步（move 包携带），客户端视线轴滚转对齐速度屏幕投影。

## Considered Options

- **保持静态末盒 + impact 重查**：否决——漏怪不修，成本不减。
- **扫掠查询仅撞怪分支使用、撞墙保留静态重查**：否决——撞墙分支语义分裂，贴墙怪直击需要第三套查询，且"穿过即命中"不成立。
- **查询后逐候选路径精判**：否决——无碰撞时与并集等价，碰撞时差异仅轴锁角落，收益小于一个 10 行 slab 的成本。
- **命中点取 tick 末位置**：否决——高速弹溅射/破片整体偏后 ≤1.5 格，正是本决议要消除的偏差。
- **命中点取目标中心**：否决——多候选同 tick 重叠时"哪个目标"无定义，且中心与进入点相差 ≤半个目标，进入点顺带解决选择问题。

## 后果

- 撞墙分支行为变化：路径上被穿过的怪现在吃直击（旧实现只有贴墙怪吃）。方向正确，无测试回退。
- 溅射几何以进入点为中心：高速弹命中时爆点与目标贴合，碎片从真命中点喷出。
- slab 测试与并集查询共用 inflate 0.15 口径，命中点与伤害盒一致。
