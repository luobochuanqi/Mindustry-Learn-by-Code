# MTurrets

把 Mindustry 的炮台、机器与材料玩法移植到 Minecraft 的 NeoForge 模组,目前仍在开发中。

**当前版本:`1.0-SNAPSHOT`(测试版)。请勿用于生产环境或正式存档,数据兼容性不做保证。**

- Minecraft 1.21.1 / NeoForge 21.1.248
- Kotlin(KotlinForForge 5.12+)

## 资产声明

`arc`、`meltdown`、`duo` 的贴图提取自 [Mindustry](https://github.com/Anuken/Mindustry)(GPL-3.0),提取说明见 [ATTRIBUTION.md](src/main/resources/assets/mturrets/textures/ATTRIBUTION.md)。本仓库整体以 GPL-3.0 发布。

## 贡献
